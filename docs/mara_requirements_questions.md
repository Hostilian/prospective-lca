# Pilot decision sheet

For technical discussion with Dr. Mara Silva / AWAM · 5 October 2026

The workbench is ready for software review. This sheet defines the evidence needed for one real pilot: a reconciled baseline and two future cases. It assumes the reader is familiar with LCA.

| Decision | Record before implementation | Proposed owner |
|---|---|---|
| Pilot and decision | Process/model identifier, decision question, intended use; clarify whether “Project LIFE” names a specific project | AWAM scientific owner |
| Function and comparison | Treatment service, FU/reference flow, moisture, output quality, boundary, counterfactual and co-product rule | Scientific owner |
| Calculation route | openLCA version, database/version/system model, LCIA method/version/categories; safe model/export | Model/data owner |
| Process evidence | Measured mass/energy balance, yields, throughput, scale, sampling dates, source files and uncertainty basis | Process owner |
| Future cases | Two coherent pathways, target years, geography, engineering changes, background scenario/version and rationale | Scientific owner |
| Reconciliation | Independent baseline result, absolute/relative tolerances agreed in advance, reviewer and discrepancy procedure | Reviewer |
| Data and handover | Approved local directory, access rights, software licence/IP, confidentiality and permitted claims | AWAM / Eren |

## Acceptance sequence

1. Freeze the approved reference model and evidence register.
2. Reproduce and independently reconcile the baseline.
3. Implement the two approved future cases with transformation provenance.
4. Test the agreed sensitivities and document uncertainty limits.
5. Reproduce the complete package on a second researcher's machine and record acceptance.

The demonstration's fertiliser credit, proxy indicators and simple scale multipliers are not defaults for the real pilot. None of these decisions has been attributed to Dr. Silva or marked approved.
