# Report specification: review edition 1.1

Updated 5 October 2026 following the request for a finished technical submission addressed to a researcher familiar with LCA. This audience instruction supersedes the earlier beginner-reader assumption. Prepared by Eren Ozturk; English; unbranded independent prototype.

## Deliverables

- **Study brief** at `/customer/` and `/`: concise scope, conditional cases, proxy comparisons, contributions, ordered decomposition, proposed ledger and pilot acceptance.
- **Technical review** at `/reviewer/`: the same evidence plus credit-exclusion, reverse-order and interaction checks, concise notation and source/verification detail.

Each is one standalone HTML file with inline CSS/SVG and optional print-button JavaScript. Core content must work without JavaScript or external assets. Supporting data links require the complete export package.

## Numerical contract

The supplied display dataset remains unchanged. Preserve exact totals, original percentages and contribution labels in the appendix. Use three significant figures in the main table and two decimals in the percentage chart, with explicit discrepancy disclosure. Keep signed credits and the tiny water contribution visible without exaggerating its scale.

Derived checks use the original synthetic quantity/factor model and are separately labelled. They must never overwrite headline values. Reproduce the source calculation and verify its manifest before attaching its provenance to the reports.

## Acceptance

Check both routes on desktop/mobile in light/dark mode, keyboard navigation, JavaScript disabled, and A4 print. Inspect charts, table wrapping, contrast, overflow and console/network errors. Verify fingerprints and reject modified calculation/documents. Keep synthetic/unapproved-method status visible at entry.

The review package may be shared for software/method discussion with its status intact. Sending it as a validated scientific result remains inappropriate: the real pilot, measured inventory, approved methods and scientific acceptance are outstanding.
